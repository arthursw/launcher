# Single-window installer demo

This interactive visual prototype explores a launcher layout where first-run choices, progress, and results share one window while the activity log remains visible throughout.

Open `index.html` in a browser, or serve this directory with any static file server.

The “Preview state” menu jumps between representative states.
The in-window buttons also demonstrate the intended progression from location choice through existing-install handling and installation.

This is a design prototype, not the production launcher GUI implementation.
